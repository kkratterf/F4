F4 is not notarized by Apple yet. Open it once and close the warning, then go to System Settings → Privacy & Security and click Open Anyway. Or run xattr -dr com.apple.quarantine /Applications/F4.app in Terminal.

On a Mac keyboard the top row are media keys first. Hold fn and press F4, or turn on Use F1, F2, etc. keys as standard function keys in System Settings → Keyboard → Keyboard Shortcuts → Function Keys. Or let F4 catch the key: turn on Open F4 with the F4 key alone, without fn (F4 offers it on the first launch). It needs the Accessibility permission; without it fn F4 keeps working. On most other keyboards F4 just works. Or pick another shortcut in Settings.

F4 only goes online to check for updates against the release feed on this site, to search GIPHY while you are in the GIFs or Stickers tab, and to download an image link you paste or drop into the panel. By itself. F4 checks for a new version about once a day and installs it in one click, signed and verified. You can also check by hand from the menu bar icon.
