Three steps, no thinking

F4 reads one folder on your Mac. Your memes stay yours: nothing is uploaded anywhere.

Put your memes in a folder

~/Pictures/Memes by default, or any folder you pick. Subfolders become categories.

Press ⌘⇧M

From any app. The panel floats above everything, even full-screen apps, and opens instantly.

Type, then Enter

The meme is copied. Paste it with ⌘V — or let F4 paste it for you.

What is in it

🎞️

GIFs stay animated

F4 copies the file itself, never a flattened image, so Slack, Discord and Telegram get the animation.

⚡️

Instant

Folder scans and thumbnails run in the background. The panel never waits, however many memes you have.

🔎

Fuzzy search

Type a few letters in any order. Favourites and the memes you use most come first.

🗂️

Categories

Subfolders show up as categories you can search, so a thousand files stay findable.

🔐

No permissions

The global shortcut needs no Accessibility or Input Monitoring. Auto-paste is optional and degrades gracefully.

🧩

Raycast too

A Raycast extension searches the same folder, if that is where your hands already are.

🇮🇹

English and Italian

The app follows your Mac's language. And yes, a few lines from Boris and The Office are hidden in the search field.

🆓

Free and open source

MIT licensed, built in the open, no telemetry. The only network request F4 makes is the update check.

Install

Needs macOS 14 Sonoma or later. Pick whichever you like.

The app

Download the DMG, open it and drag F4 onto Applications.

One line in Terminal

curl -fsSL https://raw.githubusercontent.com/kkratterf/f4/main/install.sh | sh

Homebrew

brew tap kkratterf/f4 https://github.com/kkratterf/f4
brew install --cask f4

F4 updates itself: it checks for new versions and installs them in one click, so you only do this once.

Questions

macOS says it cannot verify the developer. Now what?

F4 is not notarized by Apple yet. Open it once, close the warning, then go to System Settings → Privacy & Security and click Open Anyway. Or run xattr -dr com.apple.quarantine /Applications/F4.app in Terminal. The install script does it for you.

Where do the memes come from?

From you. F4 ships with no images at all — no copyrighted stills, no GIF packs. Point it at a folder of your own and it indexes what is there.

Does it send anything anywhere?

No. No analytics, no account, no server. Your files are read locally; the only network request is the update check against the release feed on this site.

Which files does it understand?

GIF, PNG and JPEG today. WebP, HEIC and short videos are on the roadmap.

Can I change the shortcut?

Yes, in Settings, from the menu bar icon. ⌘⇧M is only the default.

Why "F4"?

From "F4, basito", the face Stanis makes in the Italian series Boris. The face in the icon is drawn in code — put a .basito.png in your meme folder to use your own.

Can an AI assistant or a script use F4?

That is being built (a URL scheme, Shortcuts actions, a command line tool and an MCP server). Machine-readable facts about the project live in llms.txt.
