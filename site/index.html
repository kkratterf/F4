Questions.

macOS says it cannot verify the developer. Now what?

F4 is not notarized by Apple yet. Open it once, close the warning, then go to System Settings → Privacy & Security and click Open Anyway. Or run xattr -dr com.apple.quarantine /Applications/F4.app in Terminal. The install script does it for you.

Where do the memes come from?

From you. F4 ships with no images at all: no copyrighted stills, no GIF packs. Point it at a folder of your own and it indexes what is there. The GIFs on this page are shared by the shows' official channels on GIPHY and load from there.

Does it send anything anywhere?

No. No analytics, no account, no server. Your files are read locally. F4 only goes online to check for updates against the release feed on this site, and to download an image link you paste or drop into the panel.

Which files does it understand?

GIF, PNG, JPEG and WebP (WhatsApp and Telegram stickers). HEIC and short videos are on the roadmap.

Can I change the shortcut?

Yes, in Settings, from the menu bar icon. F4 is only the default; any function key works on its own, any other key with ⌘, ⌥ or ⌃.

F4 opens Spotlight or Launchpad instead. Why?

On a Mac keyboard the top row are media keys first. Hold fn and press F4, or turn on Use F1, F2, etc. keys as standard function keys in System Settings → Keyboard → Keyboard Shortcuts → Function Keys. On most other keyboards F4 just works. Or pick another shortcut in Settings.

Why "F4"?

From "F4, basito", the face Stanis makes in the Italian series Boris. The icon is the F4 key itself; the basito face shows up inside the app, drawn in code. Put a .basito.png in your meme folder to use your own.

Can an AI assistant or a script use F4?

That is being built (a URL scheme, Shortcuts actions, a command line tool and an MCP server). Facts for AI assistants live in llms.txt, and the full reference in llms-full.txt.
