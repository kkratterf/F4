# F4 for Raycast

Search your F4 stickers from Raycast and copy or paste one. It reads the same folder as the F4 app (F4's library in `~/Library/Application Support/F4/Memes` by default, or the folder picked in the app; any folder you pick in the extension preferences wins), including subfolders.

Stickers are copied as files, never as decoded images, so animated ones stay animated when you paste them into WhatsApp, Slack or Telegram.

## Develop

```bash
cd raycast
npm install
npm run dev
```
