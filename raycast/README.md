# F4 for Raycast

Search the memes in your meme folder from Raycast and copy or paste one. It reads the same folder as the F4 app (`~/Pictures/Memes` by default, or any folder you pick in the extension preferences), including subfolders.

Memes are copied as files, never as decoded images, so GIFs stay animated when you paste them into Slack, Discord or Telegram.

## Develop

```bash
cd raycast
npm install
npm run dev
```
